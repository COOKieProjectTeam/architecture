# Защищённая ветка `main`

Целевая ветка **`main`** на GitHub **защищена** (прямой push недоступен).

## Обязательный поток любых изменений

1. Выполните `git fetch origin`, ответвление от актуальной **`origin/main`**.
2. Работа — в отдельной ветке, например `docs/sync-<тема>`, `fix/readme-<тема>`, `feat/diagram-<тема>`.
3. `git push -u origin <ветка>` и открытие **Pull Request → `main`**.
4. Слияние только после ревью/проверок, заданных в настройках репозитория.

Не коммитьте и не пушьте изменения напрямую в локальный `main` с намерением «догнать origin» без PR: привычка должна быть **ветка → PR → merge**.
