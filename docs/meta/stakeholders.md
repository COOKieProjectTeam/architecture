# Стейкхолдеры

_Роли и архетипы пользователей; детали прав и границ доступа — таблица §2.2 [[../requirements/SRS|SRS]]. Дифференциация **Free / Pro** — **подписка** и **привязка фич** к тарифам; дополнительные лимиты (например объём избранного у Free) — в соответствующих FR SRS._

| Сторона | Роль | Влияние / интерес | Примечание |
|---------|------|-------------------|------------|
| Анонимный посетитель | Anonymous User | Низкий / охват воронки | Доступ к функциям воронки по политике роли и конфигу продукта; детали — SRS §2.2 |
| Зарегистрированный пользователь | Free User | Высокий / база продукта | Базовый доступ; лимит избранного и прочие границы — в SRS |
| Подписчик | Pro User | Высокий / выручка | Платный тариф **Pro** (единственный платный): ядро ценности — цепочка КБЖУ → корзина → интеграции с ритейлерами и доставкой; ИИ-диетолог — вторичная возможность подписки |
| Операции контента | Content Moderator | Средний / качество UGC | Модерация рецептов |
| Платформа | Admin | Высокий / целостность системы | Полный доступ |
| B2B | Partner Manager | Средний / каталог и заказы | Каталог готовой еды, аналитика |

_Вне **пользовательских ролей §2.2** (контуры интеграций: ритейлеры, доставка, платёжный процессинг, LLM и др.) см. вторичные акторы и границу системы в [[../architecture/functional/use-cases|architecture/functional/use-cases]] и SRS §7._

**RACI:** компактный пресет — перечень ролей закреплён в таблице выше и в [[../requirements/SRS#2.2. Пользовательские роли|SRS §2.2]] (сверка 2026-05-03); при расширении круга ответственных допускается введение отдельной матрицы RACI. На доске `summary/` и в тексте UC допустимы сокращения: **Free** = Free User, **Partner Mgr** = Partner Manager, **Moderator** = Content Moderator.
