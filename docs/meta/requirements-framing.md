# Рамка требований (§1)

_Артефакт этапа **§1 Рамка** по [[Agent Workflow — REQ+UML (мастер)|мастеру REQ+UML]] и [[Knowledge/Development/Requirements/Agent Workflow — от требований к спецификации|workflow требований §1]]. Теория-опора: [[Knowledge/Development/Requirements/01_Введение в требования и процесс управления|01 — Введение]], [[Knowledge/Development/Requirements/07_Управление требованиями в методологиях|07 — Методологии]]._

## Что считаем требованием (requirement)

**Требование** в проекте COOKie — это **проверяемое утверждение** о свойстве или поведении системы, данные, интеграции или процессе поставки, зафиксированное в vault и (после ворот) трассируемое к реализации и приёмке. Формулировки в BRD/SRS/FRS/NFR имеют приоритет над неформальными обсуждениями; изменения после стабилизации v2.0 — через [[../changes/README|Change Request]].

## Уровни: business / user / system

Согласовано с разделением уровней из курса (см. workflow §1 и лекцию 07):

| Уровень | Смысл в COOKie | Где фиксируем |
|--------|----------------|---------------|
| **Business** | Цели, метрики продукта, экономика партнёрок | [[../requirements/BRD|BRD]] (BC-*, MET-PROD, MET-TECH — высокоуровнево) |
| **User** | Сценарии «что делает человек» с точки зрения ценности и UX | [[../requirements/FRS|FRS]] (экраны/потоки), текстовые **use case** — [[../architecture/functional/use-cases|use-cases]]; роли — [[../requirements/SRS|SRS]] §2.2 |
| **System** | Поведение ПО, данные, интеграции, ограничения качества | [[../requirements/SRS|SRS]] (FR-*, DR-*, §7), [[../requirements/NFR|NFR]] |

Продуктовая формулировка «зачем продукт» для стейкхолдеров — [[../product/overview|Обзор продукта]].

## Виды требований и нотации

| Вид | Нотация / место | Примечание |
|-----|-----------------|------------|
| Бизнес-цели | BC-* | BRD |
| Продуктовые / техметрики | MET-PROD-*, MET-TECH-* | BRD (и перекрёстно SRS по аналитике) |
| Функциональные системные | `FR-*` (FR-RS, FR-US, FR-MP, …) | SRS |
| Нефункциональные | NFR-*, разделы по категориям | NFR + пересечения с SRS |
| Данные / соответствие | DR-* | SRS §6 |
| Интеграции | INT-API-*, INT-REQ-* | SRS §7 |
| Пользовательский интерфейс | FRS-*, сценарии | FRS |
