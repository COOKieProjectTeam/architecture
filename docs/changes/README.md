# Управление изменениями (Change Request)

_Формализованные запросы на изменение (workflow §6). Политика semver для пакета спецификации в vault — см. [SYNC.md](../SYNC.md)._
## Политика версии при CR (MVP)

Пока спецификация в фазе `vault_only` и до завершения MVP: **принятый** CR должен отражаться в журнале ниже (**дата**, краткий идентификатор решения); **минорная** версия пакета поднимается **2.x** на каждый такой принятый пакет правок (**2.1**, **2.2**, …). **Мажор** (**3.x**) — только по отдельному решению после MVP.
